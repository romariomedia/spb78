# SportBuddy СПб — подготовка к публикации в RuStore

**Версия:** 1.0.0 (versionCode 1)
**applicationId:** `ru.sportbuddy.mobile`
**Возрастная категория:** 18+
**Категория RuStore:** Здоровье и фитнес / Знакомства
**Регион распространения:** Российская Федерация (г. Санкт-Петербург)

---

## 1. Сборка веб-части

```bash
npm install
npm run build        # → dist/
```

## 2. Инициализация и сборка Android

```bash
npx cap add android
npx cap sync android
npx cap open android
```

Сборка релизного AAB (требуется RuStore):

```bash
cd android
./gradlew bundleRelease
# → android/app/build/outputs/bundle/release/app-release.aab
```

## 3. Подпись приложения

```bash
keytool -genkey -v -keystore sportbuddy-release.keystore \
  -alias sportbuddy -keyalg RSA -keysize 2048 -validity 10000
```

`android/key.properties`:

```properties
storeFile=../sportbuddy-release.keystore
storePassword=<ПАРОЛЬ>
keyAlias=sportbuddy
keyPassword=<ПАРОЛЬ>
```

> ⚠️ Keystore и пароли **не хранить в репозитории**.

## 8. Монетизация

Два тарифа: **Бесплатный** и **Premium**.
30 дней Premium бесплатно новым пользователям. Промокоды —
подарочные, без денежного эквивалента. Платежи проводятся через ЮKassa
с серверной проверкой webhook перед активацией Premium.

## 9. Чистый старт пользователя (production)

Финальная сборка гарантирует честный рейтинг с первого дня:

| Что | Поведение |
|---|---|
| Статистика нового аккаунта | Все счётчики = **0**: тренировки, медали, рейтинг, серия, боксы |
| Уровень медалей | Всегда стартует с **Бронзы** |
| Друзья и мэтчи | Пустые списки — никаких предустановленных связей |
| Чаты | Пустые, тред создаётся только после реальной взаимной симпатии |
| Уведомления | Одно приветственное, без выдуманных мэтчей и сообщений |
| Сброс устройства | `resetLocalProgress()` очищает прогресс предыдущего аккаунта |

**Боты не попадают в Firestore.** Демо-профили существуют только в локальном
зеркале, помечены `isDemo: true`, показываются с плашкой «Пример анкеты»
и **исключены из таблицы лидеров** и статистики сообщества.

## 11. Финальный аудит (web + Android/iOS)

### Производительность
- [x] Виртуализация списков (`react-virtuoso`) — тренировки и лента
- [x] `React.memo` на тяжёлых карточках и секциях профиля
- [x] Ленивые изображения (`loading="lazy"`, `decoding="async"`, `content-visibility`)
- [x] GPU-композитинг анимаций (`will-change`), только `transform/opacity`
- [x] Stable-ссылки колбэков (`useCallback`) — мемо-компоненты не перерисовываются зря
- [x] Service Worker network-first, не кеширует API/Firestore/Storage
- [x] PWA-манифест подключён в `index.html`

### Устойчивость
- [x] `AppErrorBoundary` — нет белого экрана при падении виджета
- [x] Все сетевые вызовы с таймаутом и понятными русскими ошибками
- [x] Загрузка фото: same-origin → production fallback, ясная ошибка при сбое
- [x] Firestore offline-first: персистентный IndexedDB-кеш, очередь офлайн-операций
- [x] Сплэш-фейлсейф 6 с — загрузка не зависает при обрыве сети

### Авторизация
- [x] VK ID — основной вход; e-mail + пароль + восстановление — резерв
- [x] Биометрия (WebAuthn) для быстрого разблокирования
- [x] Удалённый аккаунт может зарегистрироваться заново с тем же e-mail
- [x] Выход полностью сбрасывает сессию, admin-сессию и состояние приложения

### Хранилище медиа
- [x] Firebase Storage полностью удалён из клиента
- [x] Аватар, портфолио, лента, промо-медиа → Yandex Object Storage
- [x] Секретные ключи только в серверной serverless-функции
