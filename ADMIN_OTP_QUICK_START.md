# Быстрый старт: OTP авторизация администратора

## 🚀 Что сделано

✅ **AdminOTPModal.tsx** — красивая UI модалка с тремя экранами
✅ **adminAuth.ts** — полный сервис управления OTP сессиями  
✅ **send-admin-otp.js** — API для отправки писем на SMTP
✅ **Интеграция в App.tsx** — кнопка админа открывает OTP модалку
✅ **1-часовые сессии** — автоматический выход после истечения времени

---

## 📧 Что нужно настроить (5 минут)

### 1. Переменные окружения
В `.env.production` добавьте SMTP параметры:

```bash
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-email@gmail.com
SMTP_PASS=xxxx xxxx xxxx xxxx
SMTP_FROM=noreply@sportbuddy78.pro
```

**Для Gmail:**
- Включите 2FA: https://myaccount.google.com/security
- Создайте App Password: https://myaccount.google.com/apppasswords
- Скопируйте 16-символьный пароль в `SMTP_PASS`

### 2. Развёртывание
```bash
npm install
npm run build
# На Vercel: git push (автоматически деплоится)
# На другом хостинге: убедитесь что `api/send-admin-otp.js` доступен как функция
```

### 3. Проверка
- Откройте приложение → профиль → кнопка "🗝️ Кабинет администратора"
- Нажмите "📧 Отправить код"
- Проверьте `support@sportbuddy78.ru` — должно прийти письмо с кодом

---

## 🔄 Как это работает

```
Админ нажимает кнопку
  ↓
Модалка: "Отправить код"
  ↓
API генерирует 6-значный код + сохраняет в Firestore
  ↓
Email отправляется на support@sportbuddy78.ru
  ↓
Админ копирует код из письма
  ↓
Вводит в поле модалки
  ↓
Система проверяет, создаёт 1-часовую сессию
  ↓
Админ получает доступ в кабинет
```

## 🛡️ Безопасность

- Коды одноразовые (удаляются после использования)
- Истекают через 15 минут
- Сессии истекают через 1 час → заново авторизоваться
- Хранятся в `sessionStorage` браузера
- SMTP запросы зашифрованы (TLS/SSL)

## ❓ FAQ

**Q: Где хранятся коды?**
A: В Firestore коллекции `admin_otp_codes`. Удаляются после использования или истечения.

**Q: Что если админ не получил письмо?**
A: Проверьте спам-фильтр, логи сервера, SMTP параметры.

**Q: Можно ли изменить время действия кода?**
A: Да, измените `OTP_VALIDITY_MINUTES` в `src/services/adminAuth.ts` (сейчас 15 минут).

**Q: Можно ли удлить сессию?**
A: Измените время в `adminAuth.ts` где создаётся сессия (сейчас 60 минут).
