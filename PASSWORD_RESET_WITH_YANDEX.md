# Система восстановления пароля с Яндекс.Почтой

## 📋 Как работает система

### **Проблема: текущая система (Firebase Password Reset)**
- ❌ Письма приходят от Firebase (невозможно кастомизировать)
- ❌ Ссылки не гибкие
- ❌ Сложно отследить восстановления
- ❌ Дизайн письма стандартный

### **Решение: новая система с Яндекс.Почтой**
- ✅ Письма приходят от вашего адреса (`admin-sportbuddy@yandex.ru`)
- ✅ 6-значный код + красивая кнопка в письме
- ✅ Полный контроль над процессом
- ✅ Красивый HTML-дизайн письма
- ✅ Коды сохраняются в Firestore (отслеживание)
- ✅ Автоматическое удаление старых кодов

---

## 🏗️ Архитектура

```
Пользователь забыл пароль
    ↓
"Восстановить пароль" → вводит email
    ↓
api/send-password-reset.js (Node.js)
    ↓
Генерируем: 6-значный код + reset-ссылку
    ↓
Сохраняем в Firestore: password_reset_codes
    ↓
Отправляем письмо через Яндекс.Почту (nodemailer)
    ↓
Пользователь получает письмо с кодом и ссылкой
    ↓
Вводит код в приложение ИЛИ кликает ссылку в письме
    ↓
verifyPasswordResetCode() проверяет код
    ↓
Если верный → помечаем как использованный
    ↓
Пользователь устанавливает новый пароль
```

## ⚙️ Настройка (используется та же Яндекс.Почта)

Используйте **те же SMTP-параметры**, что и для OTP администратора:

```bash
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=admin-sportbuddy@yandex.ru
SMTP_PASS=abcd efgh ijkl mnop
SMTP_FROM=admin-sportbuddy@yandex.ru
```

**На Vercel:**
- Settings → Environment Variables
- Добавьте те же 6 переменных (если уже есть из админки OTP, не дублируйте)

## 🔐 Различия между системами

| Фактор | Firebase Password Reset | Новая система с Яндекс |
|--------|-------------------------|-------------------------|
| **Отправитель** | noreply@firebase.com | admin-sportbuddy@yandex.ru |
| **Дизайн письма** | Стандартный Firebase | Кастомный красивый |
| **Код в письме** | Нет (только ссылка) | ✅ 6-значный код |

| **Хранение кодов** | Firebase Auth | Firestore (контролируется) |
| **Отслеживание** | Ограниченное | Полное (Firestore) |
| **Персонализация** | Невозможна | ✅ Полная |
| **Стоимость** | Бесплатно | Бесплатно (Яндекс) |

11. **Успешно вошли!** ✓

## 🛡️ Безопасность

✅ **Коды одноразовые** — после использования удаляются  
✅ **Коды истекают** через 30 минут  
✅ **Email-верификация** — ссылка отправляется на подтвержденную почту  
✅ **Попытки ограничены** — в коде есть счётчик `attempts`  
✅ **HTTPS-ссылки** — все ссылки защищены TLS  
✅ **Старые коды удаляются** — функция `cleanupExpiredResetCodes()`

## 📊 Сравнение: Firebase vs Яндекс.Почта

### **Firebase Password Reset**
```typescript
// Текущая реализация
export async function requestFirebasePasswordReset(email: string) {
  await sendPasswordResetEmail(auth, email, {
    url: 'https://sportbuddy78.pro',
    handleCodeInApp: false
  });
}
```
**Недостатки:**
- Firebase управляет письмом (стандартный дизайн)
- Сложно кастомизировать
- Нет контроля над сроками

### **Новая система с Яндекс + Firestore**
```typescript
// Новая реализация
export async function sendPasswordReset(email: string) {
  const code = generateResetCode();      // 123456
  const token = generateResetToken();    // Уникальный токен
  
  // Сохраняем в Firestore
  await setDoc(doc(db, 'password_reset_codes', resetId), {
    email, code, resetUrl, expiresAt, attempts: 0
  });
  
  // Отправляем через API → Яндекс.Почту
  await fetch('/api/send-password-reset', {
    body: JSON.stringify({ email, code, resetUrl })
  });
}
```
**Преимущества:**
- Полный контроль над письмом
- Красивый дизайн
- Отслеживание (Firestore)
- Гибкие сроки (можно менять)
- Удобный 6-значный код

## ⚠️ Возможные проблемы

### **Письмо не приходит?**
1. Проверьте SMTP-параметры в .env
2. На Vercel проверьте Environment Variables
3. Проверьте спам-фильтр
4. Логи: https://vercel.com/dashboard → Deployments → Logs

### **Ошибка: "Неверный код"**
1. Скопируйте код точно, без пробелов
2. Проверьте, не истёк ли 30-минутный срок
3. Коды одноразовые — новый можно запросить

### **Ошибка: "Email не найден"**
1. Убедитесь, что email зарегистрирован в приложении
2. Проверьте правильность написания
