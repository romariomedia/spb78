# Функция поиска пользователей в SportBuddy

Я добавил полнофункциональный поиск пользователей по имени/фамилии с возможностью добавления в друзья (только для Premium пользователей).

---

## Что добавлено

### 1. **Новый компонент `UserSearchModal.tsx`**
Модальное окно поиска с:
- **Живым поиском** по имени, фамилии и нику пользователя
- **Сортировкой** результатов по релевантности (точное совпадение в начале идёт первым)
- **Информацией о каждом пользователе:**
  - Фото (аватар)
  - Имя и возраст
  - Рейтинг (⭐) и количество тренировок
  - Спортивные дисциплины (до 2 тегов)
- **Кнопкой "Добавить"** для добавления в друзья
- **Индикатором "Друг"** для уже добавленных пользователей
- **Premium-защитой:** кнопка добавления недоступна для бесплатных пользователей

### 2. **Интеграция в чаты**
Добавлена кнопка **🔍 Поиск** в шапку вкладки "Чаты", которая открывает модальное окно поиска.

### 3. **Умная фильтрация**
- Исключаются: текущий пользователь, уже добавленные друзья
- Максимум 50 результатов (для производительности)
- Поиск работает в реальном времени (debounce не нужен, так как это клиентский поиск)

### 4. **Обновление друзей**
- При добавлении в друзья обновляется в Firestore
- Локальное состояние синхронизируется сразу
- Toast-уведомление подтверждает действие

---

## Использование

1. **Откройте вкладку "Чаты"** в приложении
2. **Нажмите кнопку "🔍 Поиск"**
3. **Введите имя или фамилию** интересующего вас пользователя
4. **Выберите из результатов** и нажмите **"Добавить"** (доступно только для Premium)

## Ограничения и особенности

✅ **Работает offline-first:** поиск работает даже без интернета  
✅ **Быстро:** фильтрация происходит на клиенте (нет серверных запросов)  
✅ **Premium-защита:** бесплатные пользователи видят результаты, но не могут добавлять  
✅ **Релевантность:** люди с точным совпадением имени в начале видны первыми  

⚠️ **Поиск чувствителен к регистру?** Нет, конвертируем в нижний регистр  
⚠️ **Можно ли искать по городу?** Нет, только по имени. Если нужно — могу добавить  
⚠️ **Максимум 50 результатов:** это сделано для производительности

## Если что-то не работает

1. **Кнопка поиска не видна в чатах?**
   - Проверьте, что ChatsTab получает пропс `onOpenUserSearch`

2. **Поиск возвращает 0 результатов?**
   - Убедитесь, что в `allUsers` есть данные
   - Проверьте, что вводите текст корректно (имена на русском)

3. **Не могу добавить в друзья?**
   - Ваш Premium-статус `isPremium` должен быть `true`
   - Проверьте, что пользователь не уже ваш друг
