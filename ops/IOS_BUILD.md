# SportBuddy78 для iPhone

## Что добавлено

Нативный проект `ios/App/App.xcodeproj`, Capacitor 8.5.1, iOS 15+.
Bundle ID: `ru.sportbuddy.mobile`; название на экране: SportBuddy78.
Иконка — существующий S78; заставка — тот же логотип на тёмном фоне.
Общие React-функции, аккаунты и сервер используются вместе с Android и сайтом.
Изменения контента в админке не требуют новой iOS-сборки. Изменения встроенного интерфейса требуют.

## Автоматическая проверка без Mac у владельца

GitHub → Actions → **iOS build verification** → Run workflow → main.
Workflow также запускается при изменении нативного iOS-проекта в main.
GitHub использует macOS с Xcode 26, устанавливает зависимости по lockfile, запускает тесты,
собирает веб-ресурсы и выполняет `cap sync ios`. Затем компилирует симулятор и архив для устройства.
Проверка может расходовать минуты GitHub Actions согласно тарифу репозитория.

Артефакты:
- `SportBuddy78-simulator.zip`: `.app` для Simulator на Mac, не для iPhone.
- `SportBuddy78-unsigned.xcarchive.zip`: архив для устройства **без подписи**. Не устанавливается на iPhone и не загружается в TestFlight в таком виде.

## Установка на реальный iPhone

Для распространения через TestFlight нужны членство Apple Developer, команда (Team ID),
зарегистрированный Bundle ID и карточка приложения в App Store Connect.
Секреты, сертификаты и пароли не коммитить и не отправлять в чат.

На Mac с Xcode 26+ и Node 22+:

```sh
npm ci
npm run ios:sync
npm run ios:open
```

В Xcode: App target → Signing & Capabilities → Team владельца → Automatically manage signing.
Для личного устройства выберите подключённый iPhone и Run. Возможности бесплатной Personal Team
ограничены; это не распространение пользователям.
Для TestFlight: выберите Any iOS Device → Product → Archive → Distribute App → App Store Connect.
Перед каждой загрузкой увеличьте Build (`CURRENT_PROJECT_VERSION`); для нового релиза также Version.
Вход в Apple ID, подпись и разрешения на публикацию выполняет владелец.

## VK

VK продолжает использовать HTTPS redirect `https://sportbuddy78.pro/vk-callback` существующего web client ID.
На iPhone веб-страница возврата показывает кнопку с фиксированной схемой `sportbuddy78://vk-callback`.
iOS зарегистрирована для этой схемы. Приложение восстанавливает HTTPS callback и проверяет сохранённые state,
PKCE и срок сессии перед обменом кода. Токен в URL возврата не передаётся.
Нужно выложить обновлённый веб-фронтенд на VPS, иначе страница будет предлагать Android intent.
Не меняйте работающие Android redirect URL.
До реального теста на iPhone вход VK не считать подтверждённым.

## Разрешения и уведомления

Камера, медиатека, запись звука и геопозиция имеют русские описания в Info.plist.
Разрешения запрашиваются при использовании функции; фоновая геолокация не включена.
Встроенный список уведомлений работает через общий API.
Нативные push на iOS пока не подключены: Android FCM token и iOS APNs token несовместимы.
Кнопка включения объясняет ограничение, Web Push внутри WKWebView не запускается.
Следующий этап — iOS-приложение в Firebase, APNs key владельца, native Firebase Messaging integration
и проверка доставки после блокировки экрана. До этого не обещать push на iPhone.

## Перед TestFlight и публикацией

На реальном устройстве проверить:
1. Вход по почте, выход, сохранение сессии после перезапуска.
2. VK: успешный вход, отмена, возврат из Safari при закрытом и открытом приложении.
3. Список атлетов, профиль, аватар, портфолио, лента и истории.
4. Камера/галерея, геопозиция с разрешением и отказом, запись видео со звуком.
5. Создание и запись на тренировку, чаты, друзья, карточки отдыха и площадок.
6. Внешние ссылки, клавиатура, безопасные отступы на iPhone, поворот экрана.
7. Удаление аккаунта и настройки приватности.

Это техническая сборочная основа, не заявление о готовности к App Store Review.
Перед публичной отправкой отдельно проверить требования Apple к авторизации, платным цифровым функциям,
модерации пользовательского контента, сведениям о приватности и privacy manifests зависимостей.
Не отключать проверку TLS и не добавлять NSAllowsArbitraryLoads для устранения сетевых ошибок.
