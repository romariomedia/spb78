# Персональные тренеры SportBuddy78

## Для пользователя

1. В «Профиль → Обзор» отметить «Я персональный тренер».
2. Выбрать дисциплины из общего каталога видов спорта SportBuddy78.
3. Нажать «Продолжить в Спортивном ID». Выбор сохраняется, но знак ещё не выдаётся.
4. В разделе проверки квалификации указать название курса / квалификацию, учебную организацию, год; приложить 1–5 документов (JPG, PNG, WebP, PDF до 10 МБ каждый). Дополнительно можно указать HTTPS-ссылку на учебный центр / реестр.
5. Отправить заявку. Статус и комментарий команды доступны здесь же; есть обновление статуса и отмена ожидающей заявки.

При отклонении можно дополнить материалы и отправить новую заявку. При изменении дисциплин или отключении галочки текущая заявка отменяется, подтверждение отзывается. Для нового набора дисциплин требуется новая проверка.

## Для команды

Админка → Verification Center → «Только персональные тренеры». Открыть документы и проверить, что они относятся к пользователю и подтверждают выбранные дисциплины. Затем подтвердить или отклонить с объяснением. Действующее подтверждение можно отозвать с указанием причины.

Кнопка «Подтвердить» выдаёт знак «Персональный тренер», добавляет пользователя в отдельный каталог в разделе «Тренировки» и исключает его из рейтинга атлетов. Медали, зачтённые тренировки и остальные достижения не удаляются. Отзыв или отключение статуса возвращает пользователя в рейтинг атлетов.

Это ручная проверка предоставленных сведений командой SportBuddy78, а не государственная сертификация. Услуги, расписание, оплата и бронирование тренера в этом обновлении не вводятся. Из каталога открывается обычная анкета с существующими возможностями общения.

## Техническая схема

- Общий каталог дисциплин: `shared/sports.js`.
- `users/{uid}.personalTrainer`: enabled, sports, status, verifiedAt. Записывается только сервером.
- Заявка: `sportVerificationRequests`, тип trainer, фиксированный claimId trainer. Документы, описание обучения, решение и комментарий хранятся в заявке.
- Подтверждение: `sportVerifiedClaims`. Операции команды пишут `adminAuditLogs` в той же транзакции.
- Действия `/api/sport-id-verification`: trainerRead, trainerSave, trainerSubmit, trainerCancel, trainers. Требуется Firebase ID token и активный аккаунт.
- Админские операции используют существующий `/api/admin-sport-id-verification` и OTP-сессию.
- Отправка, отмена, изменение дисциплин и решение команды транзакционны. Проверяется актуальный набор дисциплин; отменённую / устаревшую заявку одобрить нельзя.
- Публичные ответы содержат только подтверждённый статус, дисциплины и дату подтверждения. Ссылки на документы, комментарии команды и обучение не включаются в публичную анкету.
- Документы загружаются существующим Cloudinary-механизмом. Исключение ссылок из публичной анкеты не делает сами Cloudinary URL приватными: не просите паспорт или лишние персональные данные.
- Каталог читает по 24 записи, исключает заблокированные и тестовые аккаунты. Использует стандартный индекс personalTrainer.status; отдельная миграция данных не требуется.
- Изменения статуса сбрасывают серверный кэш публичных анкет и рейтинга. На открытом экране пользователь может обновить каталог / статус.

## Выпуск и проверка

Сначала развернуть сервер и сайт стандартными prepare-release / activate-release. Предыдущее обновление с кнопками установки iPhone / Android включено. Существующий скачиваемый APK v27 не меняется автоматически; для нового интерфейса тренеров в установленном Android-приложении собрать и распространить новый APK. Для iPhone PWA достаточно обновить сайт.

После выпуска проверить одним тестовым аккаунтом: включение → выбор спорта → загрузка документа → заявка → одобрение в админке → знак в профиле и каталог → изменение дисциплин → исчезновение подтверждения → новая заявка / отзыв. Убедиться, что медали и тренировки не изменились.

Автотесты `tests/personal-trainer.test.js` проверяют права переходов, устаревшие заявки, отмену, повторную отправку, атомарность аудита, публичные поля, фильтрацию рейтинга и страницы каталога. Загрузку в конкретный Cloudinary preset и отображение на реальном телефоне необходимо проверить после выпуска.
