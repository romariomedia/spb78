## Источники

Точные ссылки на расписание и исходную обложку каждой карточки: `data/city-events-spb-2026-10-sources.json`. Данные: `data/city-events-spb-2026-10.json`.

СКА: официальный билетный календарь клуба/СКА Арены. Футбол: официальный календарь ФК «Зенит» и официальный билетный раздел клуба. Баскетбол: официальные билетные страницы БК «Зенит». Волейбол: анонсы КСК «Арена» и её билетные ссылки. «Шанхай Дрэгонс»: официальный календарь и билетный раздел клуба.

Для исходной выборки используются локально сохранённые event-specific обложки. Для новых ноябрьских карточек СКА, ФК «Зенит» и БК «Зенит» используются уже утверждённые постоянные обложки SportBuddy78; для «Шанхай Дрэгонс — Лада» добавлена нейтральная фирменная обложка SportBuddy78 без клубных логотипов. Такие обложки не выдаются за официальные афиши. Права на исходные материалы остаются у владельцев.

## Импорт на VPS

После активации релиза из его каталога:

```bash
node --env-file=.env scripts/import-city-events.mjs
node --env-file=.env scripts/import-city-events.mjs --apply
```

Первый запуск — план, второй — запись в Firestore `sportbuddy-spb`. Create-only: сохраняет участников и скрытые карточки, пропускает начавшиеся события, проверяет весь набор до записи. Квитанции `catalogImports` сохраняют последующие удаления администратором. Дубли определяются по спорту, московской дате, названию или командам. Ручное название без полей команд может потребовать проверки.

Карточки редактируются в существующей админке городской афиши. При переносе менять вручную: это разовая подборка, не автоматическая синхронизация. Массовые push импорт не отправляет. «Иду» означает поиск компании, не билет/бронь.

Установленный APK получит события после обновления данных. Для нового оформления баннеров и фильтра «Волейбол» нужна следующая сборка APK.

## Проверка

Проверены повторный импорт, сохранение участников/скрытий/удалений, ручные ID, прошедшие даты и валидация целого набора. Запись в production выполняется только командой `--apply` на VPS.
