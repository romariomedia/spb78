# Виртуальный помощник Алина — первый выпуск

Служебный диалог с готовыми ответами по кнопкам. Это не реальная анкета и не свободный LLM-чат. Нет новых участников, мэтчей, массовых push или API-расходов на модель. Визуал первого выпуска — фирменная карточка со значком помощника, без фотографии человека.

После входа новых аккаунтов (зарегистрированы не более 7 дней назад) показывается приглашение открыть диалог. После «Позже», открытия или отключения оно не повторяется. Старым пользователям помощник доступен в разделе «Чаты» без навязчивого приглашения. Диалог доступен независимо от Premium. Руководство новичка имеет приоритет: помощник загружается после закрытия руководства.

Сервер хранит состояние отдельно в assistantConversations/{Firebase UID}: прочтение, отключение и последние 20 выбранных тем. Клиент не передаёт владельца; UID определяется из проверенного токена. Firestore закрывает клиентский доступ общим запретом. Свободный текст не собирается. При удалении аккаунта состояние очищается. История содержит идентификаторы тем; тексты ответов берутся из актуальной базы знаний, поэтому условия бета-периода корректно переключаются по серверному времени.

Админка → управление → доступность функций → «Алина — виртуальный помощник». Отключение проверяет и сервер. Аварийное отключение также возможно через SB_ASSISTANT_ENABLED=false и перезапуск API с обновлённым окружением. Редактор ответов в админке в этот выпуск не входит: тексты находятся в server/onboarding-assistant.js и меняются с релизом.

## Выпуск

Использовать обычные ops/prepare-release.sh и ops/activate-release.sh с конкретным опубликованным SHA. Отдельного импорта данных и новых индексов не требуется. Существующие правила Firestore не расширять. Для Android собрать новый подписанный APK: интерфейс помощника встроен в клиент. Сначала активировать сервер, затем проверять новый APK. Старые APK продолжают работать без помощника.

## Приёмка на устройстве

1. В новом тестовом аккаунте закрыть руководство: появится приглашение Алины. Открыть его; перейти в тренировки по ответу.
2. Вернуться в чаты: доступны диалог и история. Проверить на втором устройстве того же аккаунта: приветствие не повторяется.
3. Нажать «Позже», перезагрузить — приглашение не повторяется, карточка остаётся в чатах.
4. Отключить помощника, сменить устройство, проверить сохранение настройки. Включить снова вручную.
5. Сменить аккаунт: чужая история отсутствует. Гость не видит помощника.
6. Выключить функцию в админке: после обновления данных карточка исчезает; API не выдаёт ответы.
7. Отключить сеть: ошибка и повтор, без фиктивного успешного сохранения. Повтор одного запроса не дублирует ответ.

Автоматические тесты проверяют переходы состояния, идемпотентность, предел истории и границу бета-периода. Проверка реального телефона и production-базы остаётся этапом приёмки после выпуска.
