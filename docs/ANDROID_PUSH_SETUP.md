# Android push: подключение Firebase и проверка

## Однократная настройка владельцем

1. Firebase Console → проект sportbuddy-spb → Настройки проекта → Общие → Ваши приложения.
2. Выбрать уже зарегистрированное Android-приложение ru.sportbuddy.mobile. Если его нет — добавить Android-приложение с этим точным package name. Для FCM SHA-сертификат не нужен; рабочие настройки VK не менять.
3. Скачать google-services.json именно этого Android-приложения. Это НЕ сервисный аккаунт сервера и НЕ веб-конфигурация Firebase.
4. GitHub → romariomedia/spb78 → Settings → Secrets and variables → Actions → New repository secret.
5. Имя FIREBASE_ANDROID_GOOGLE_SERVICES_JSON. Значение — всё содержимое скачанного JSON без base64. Сохранить. Файл не коммитить: он игнорируется Git.
6. Обновить VPS обычными prepare-release/activate-release, затем запустить RuStore signed APK из main с увеличенным version_code и прежними signing secrets. Workflow восстановит и проверит Android-конфигурацию перед сборкой.

## Поведение

- Подключение по кнопке push в существующих настройках уведомлений; Android 13+ показывает системный запрос разрешения. При обычном входе повторный запрос разрешения не показывается.
- FCM notification + data позволяет системе показать уведомление в фоне без работающего JS. В вебе остаётся прежняя data-only доставка через service worker.
- Android-уведомление нейтральное: без имени отправителя и текста переписки. По нажатию открывается только разрешённый внутренний раздел и только для совпадающего Firebase UID.
- Канал sportbuddy, белый силуэт молнии, учёт категорий и московских тихих часов существующим worker. Тестовый push обходит тихие часы.
- При выходе удаляется локальная регистрация, предпринимается отвязка на сервере и удаление FCM-токена. При отсутствии сети отвязка может задержаться; уже доставленные/находящиеся в пути уведомления нельзя гарантированно отозвать. Нейтральный текст и проверка UID ограничивают раскрытие данных.
- Токен обновляется при повторной регистрации на входе с ранее включённым push. История уведомлений по-прежнему синхронизируется независимо.

## Приёмка на реальном Android — обязательна

Включить push → тест → свернуть приложение → тест с сайта для того же аккаунта. Затем проверить реальные сообщение и запрос дружбы со второго аккаунта, новое подходящее событие/тренировку. Нажать уведомление при свёрнутом приложении и после обычного закрытия из списка последних приложений. Проверить тихие часы, отказ в разрешении, выключение push, выход и другой аккаунт. До проверки не считать фоновую доставку подтверждённой.

Принудительная остановка Android, ограничения батареи производителя, отсутствие Google Play Services и сети могут препятствовать FCM. Доставка на Huawei без Google-сервисов этим релизом не добавляется. Нативный iOS push не входит в релиз. Firebase-конфигурация, реальная подписанная Android-сборка и доставка с устройства в среде разработки не проверены: нужен файл владельца и GitHub Actions.
