# Массаж — каталог услуг в разделе «Отдых»

Вкладка «Массаж» не содержит стартовых салонов, демонстрационных объявлений или фиктивных отзывов. При пустом каталоге отображается сообщение о подготовке раздела. Клиентский модуль загружается при открытии вкладки.

## Администратору

Админка → Массаж → Добавить объявление.

- Тип: салон или частный специалист.
- Название/имя, описание, перечень услуг и длительность, цены (свободный прайс с несколькими строками), адрес или условия выезда, район, телефон, часы приёма.
- До 8 фото/видео с загрузкой через действующую инфраструктуру Cloudinary. Файлы проходят существующие ограничения загрузчика. Можно удалить медиа из объявления и изменить порядок. Первое изображение используется как обложка; видео доступно внутри карточки без автозапуска.
- Ссылка на запись: HTTPS-сайт, HTTPS-ссылка мессенджера (например t.me) или tel:+7… для звонка.
- Без отметки «Опубликовать» — черновик. Для публикации обязательны описание, цены, адрес/условия выезда и ссылка на запись. Снять отметку и сохранить — скрыть. Удаление требует подтверждения.

После первого обновления сайта и APK новые объявления появляются через API без пересборки приложения. Проверьте ссылку исполнителя перед публикацией.

## Границы сервиса

Кнопка «Записаться» открывает внешний контакт. SportBuddy не создаёт бронь, не хранит запись на сеанс, не принимает оплату и не показывает календарь свободного времени. Отдельный счётчик или журнал кликов не добавлен. Договорённости подтверждает исполнитель.

## Технически

- `massageServices` — новая коллекция Firestore, без клиентских разрешений; существующее default-deny сохраняется.
- GET `/api/massage` — действующий Firebase ID token, проверка ограничения аккаунта, только опубликованные валидные карточки, публичная проекция без административных полей, максимум 200.
- POST `/api/admin-massage` — действующая OTP-сессия администратора, list/create/update/delete; изменения и аудит записываются одной транзакцией. Админский список ограничен 200 карточками.
- Ссылки и медиа валидируются сервером; только HTTPS для медиа, HTTPS/tel для записи; ограничены длины полей и число файлов.
- Оба маршрута добавлены в список обязательной загрузки API. Индекс составного запроса не нужен.
- Новые секреты не требуются. Для появления вкладки в Android нужна новая APK с увеличенным versionCode.

Проверки: публикация/скрытие/удаление, отсутствие и истечение OTP, пользовательская авторизация, заблокированный аккаунт, фильтрация административных полей, небезопасные ссылки, лимит медиа, пустой каталог. Реальную загрузку медиа и переход в приложение исполнителя следует проверить на устройстве после выкладки.
