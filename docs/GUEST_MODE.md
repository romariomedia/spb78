# Гостевой просмотр — 19.10.2026

Новый посетитель без сохранённой сессии попадает в гостевой интерфейс с шестью вкладками и настоящими каталогами. Существующий пользователь продолжает входить в свой аккаунт. На странице регистрации есть «Посмотреть без регистрации».

## Что видно

- Тренировки: название, спорт, день и время, публичное название площадки/район. Без координат личной встречи, описания пользователя и идентификаторов участников. Скрытые, завершённые, отменённые тренировки и официальные черновики исключены.
- Площадки: существующий каталог с сетями, филиалами, картой и карточками.
- Отдых: опубликованные направления/катки; массаж — опубликованные объявления с описанием и ценами.
- Лента: опубликованная афиша и активные предложения партнёров, если раздел партнёров включён.
- Знакомства, чаты, профиль: объяснение возможностей с кнопкой входа. Реальные анкеты, геолокации, переписки, пользовательские посты/истории и личные награды не публикуются для анонимных посетителей. Демонстрационные пользователи и фиктивные показатели не создаются.

Создать, присоединиться, записаться, написать, воспользоваться предложением — переход к существующей регистрации/входу. Внешние ссылки внутри площадок в гостевом режиме также ведут ко входу. После входа открывается выбранная основная вкладка; действие требует повторного подтверждения пользователем, автоматически никто никуда не записывается. Возврат на точную карточку пока не реализован.

## Безопасность и нагрузка

Отдельный GET `/api/guest-catalog?section=…` принимает только фиксированный список разделов и не выполняет запись. Данные формируются белым списком полей. Пользовательские API не ослаблены, Firebase Rules не меняются, анонимный Firebase-аккаунт не создаётся. Гостю не предлагается геолокация при открытии.

Сервер объединяет одновременные чтения и хранит результат до 30 секунд на процесс. Ошибка не кэшируется. Публикация/скрытие может отражаться в гостевом каталоге с задержкой до 30 секунд и после обновления раздела. На раздел — до 200 записей (площадки до 400); это обзор, а не полный экспорт базы. Если каталог не загрузился, показывается ошибка с повтором, а не успешный пустой список. Для направлений отдыха сбой управляемого каталога не подменяется стартовыми данными.

Техническое обслуживание применяется к гостевому API; выключение активного отдыха блокирует соответствующий гостевой запрос. Проверки OAuth сохраняют приоритет callback над гостевым экраном, включая Android cold-start callback.

## Выкладка и проверка

Нужны серверный релиз и новая APK с увеличенным versionCode. Новые секреты/правила Firestore не нужны. Проверить в инкогнито и после выхода из APK: каталоги → карточка → действие → регистрация → вход; затем проверить ВК на Android и возврат в приложение. Для существующего аккаунта убедиться, что чаты/профиль не менялись.
