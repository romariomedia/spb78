# Активный отдых

Отдельный раздел «Отдых»: каталог девяти направлений Санкт-Петербурга, Ленинградской области и Карелии, карточки с реальными фотографиями и официальными источниками, создание встреч, запись, выход и отмена организатором. Раздел не изменяет тренировки, спортивные награды и счётчики тренировок.

## Данные и доступ
POST /api/leisure проверяет Firebase ID token. Коллекции leisureEvents и leisureQuotas доступны только серверу через Admin SDK; не добавлять общий клиентский allow write. Каталог хранится в shared/leisure-destinations.js, фотографии — public/leisure. Существующие данные переносить не требуется. После обновления health показывает 15 маршрутов.

Создание использует общую Premium-политику, включая бесплатный тестовый период до 2027 года. Запись доступна авторизованным участникам с профилем. Мест от 2 до 30, организатор входит в лимит. Пол проверяется по серверному профилю; учитываются взаимные блокировки. Ограничение — пять новых встреч в день по Москве. Повтор создания с тем же requestId возвращает первоначальную встречу. Даты и время — московские.

Новые встречи рассылаются через существующий outbox/worker пользователям, выбравшим интерес «Активный отдых», с учётом настроек уведомлений и ограничений встречи. Изменения участия отправляются организатору, отмена — участникам. Разрешение браузера на push по-прежнему необходимо.

Каталог не бронирует транспорт, билеты или экскурсии. Условия посещения указаны в карточках со ссылками на официальные страницы. Организатор описывает точку сбора, дорогу, расходы и план. Перед поездкой участники проверяют условия на официальном сайте.

## Проверка после развёртывания
1. Открыть «Отдых» на телефоне; проверить фото, поиск и три региона.
2. Открыть карточку и создать будущую встречу с двумя местами.
3. Вторым аккаунтом записаться; проверить, что третий участник не может занять заполненное место.
4. Проверить выход, повторную запись, приглашение по ссылке и отмену организатором.
5. Проверить уведомления двух реальных аккаунтов с разрешёнными push; для анонса нового мероприятия выбрать интерес «Активный отдых».
6. Убедиться, что встреча не появилась в тренировках и не изменила медали.

Автоматически: 127 тестов прошли, TypeScript и production-сборка прошли. Реальная доставка push и действия с production Firestore требуют проверки после установки.
