# Chat v3 — взаимодействия

Релиз строится поверх Chat Storage v2 и не меняет контракт приватных медиа.

## Добавлено
- Ответ на конкретное сообщение с server-side проверкой исходного messageId.
- Индикатор «печатает…» через краткоживущий typingAt в metadata чата.
- Удаление своего сообщения «для всех» в течение 15 минут.
- Удалённое сообщение превращается в tombstone «Сообщение удалено».
- Оригинальный текст удалённого сообщения сохраняется только в server-side history как moderationText и не возвращается обычному пользователю.
- Жалоба/Moderation Center использует moderationText, если сообщение было удалено.
- Unread metadata корректируется при удалении непрочитанного сообщения.
- Reply на уже удалённое сообщение запрещён сервером.

## Почему фото в личных сообщениях пока не включены
Текущий Cloudinary pipeline использует unsigned public upload. Для личных чатов это недостаточный privacy contract. Медиа для DM нужно внедрять отдельным этапом через приватное/signed storage и серверную авторизацию доступа.

## Почему групповые чаты тренировок отдельно
Групповой чат меняет модель participantIds, join/leave/rejoin, историю после выхода, блокировки и модерацию. Это отдельная вертикаль Chat Groups.
