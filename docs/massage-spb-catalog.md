# Подборка массажных SPA Санкт-Петербурга — 21.10.2026

Это редакционная подборка 10 конкретных филиалов, а не объективный рейтинг всех салонов города и не список партнёров. Критерии: высокая оценка на Яндексе, не менее 100 доступных отзывов, повторяющиеся положительные отзывы о мастерах/сервисе/атмосфере, подтверждение адреса официальным сайтом, разные районы и форматы. Рейтинг не гарантирует качество отдельного визита.

Оценки и количество отзывов — снимки прочитанных страниц (часть страниц предоставляется поиском из индекса), не live-счётчик. Дата означает дату исследования, не дату последнего посещения места. Количество оценок и количество текстовых отзывов не смешиваются. Посетитель может открыть источник. Полный независимый аудит всех отзывов и личное посещение не проводились. У Baan Thai на официальном сайте есть акция за отзыв, поэтому рейтинг этого салона следует оценивать с учётом возможного смещения. У Вай Тай встречаются замечания к условиям сертификатов и выбору масел; условия следует уточнять при записи.

## Установка

После подготовки и активации релиза на VPS:

```bash
cd /opt/sportbuddy-current
node --env-file=.env scripts/import-massage-catalog.mjs
node --env-file=.env scripts/import-massage-catalog.mjs --apply
```

Без `--apply` — проверка базы и план без записей. Используется существующий серверный сервисный ключ, он не выводится. Импорт ограничен Firebase-проектом `sportbuddy-spb`.

Документы создаются в `massageServices` с постоянными ID `spa-spb-*`. Для каждой карточки в одной транзакции создаётся отметка `catalogImports/spb-spa-2026-10-spa-spb-*`. Повторный запуск безопасен, в том числе после частичного сбоя; существующий документ не перезаписывается. Отметка импорта сохраняется после удаления объявления через админку: карточка не воскресает при повторном импорте.

Карточки доступны в «Отдых → Массаж» и в админке. Гости получают существующую безопасную проекцию каталога. Администратор меняет фото, описание, цену, контакты, скрывает/удаляет карточки. При замене филиала необходимо убрать старые сведения о рейтинге кнопкой в форме. Для обновления снимка рейтинга нужен новый проверенный источник; автоматической синхронизации с Яндексом нет.

Существующий APK получает карточки и фото через сервер без пересборки. Новый блок рейтинга/ссылки на отзывы появится в APK после пересборки; на сайте — после обновления релиза. Бронирование и оплата остаются на стороне исполнителя.

## Проверка и откат

383 автоматических теста и production-сборка проходят. Отдельные тесты проверяют уникальность 10 обложек, публикацию, сохранение источников при редактировании, безопасные URL, гостевую проекцию, dry-run и повторный импорт после скрытия/удаления. Реальный импорт в боевую базу из среды разработки не выполнялся.

Для снятия подборки с публикации выключите «Опубликовать» у нужных карточек через админку. Откат кода не удаляет данные из Firestore. Не удаляйте `catalogImports`, если хотите сохранить защиту от повторного создания удалённых карточек.
