# SportBuddy78 — матрица сроков хранения данных

Редакция: 26.10.2026

> Это рабочая матрица. Для категорий, зависящих от окончательной квалификации SportBuddy78 как ОРИ, бухгалтерского режима и договоров с обработчиками, автоматическое уничтожение запрещено до письменного подтверждения срока.

| Категория | Рабочий срок / событие | Основание / правило | Автоудаление сейчас |
|---|---|---|---|
| Аккаунт и профиль | До удаления аккаунта + период, необходимый для исполнения закона/споров | Исполнение соглашения, 152-ФЗ | Только после отдельного review |
| Публичное согласие | История grant/revoke хранится как доказательство законности обработки | 152-ФЗ, доказуемость согласия | Нет |
| Публичный кэш | Короткий технический TTL, немедленная инвалидация при отзыве | Минимизация данных | Да |
| Фото/портфолио | Пока нужны профилю; после удаления — по политике удаления и резервным копиям | 152-ФЗ | После миграции в контролируемое хранилище |
| Геолокация профиля | Точная текущая точка — только для функции; публично только огрубленная | Минимизация, отдельное согласие | Требует отдельной политики |
| Feed-посты | До удаления пользователем/модерацией, если иное не требуется законом | Пользовательский контент | Частично |
| Согласие на каждый Feed-пост | Не меньше срока существования поста + разумный доказательный период | Доказательство законности распространения | Нет |
| Жалобы/модерация | До закрытия + срок для споров/защиты прав | Законный интерес/защита прав | После утверждения срока |
| B2B договоры | В течение обязательных сроков бухгалтерского/налогового и договорного хранения | ГК/налоговый/бухгалтерский учет | Нет |
| Платежи/чеки/ledger | По обязательным срокам учета и требованиям платежной/кассовой системы | 54-ФЗ, налоговый учет | Нет |
| Админ-аудит | Не менее внутреннего срока безопасности и споров; конкретный срок утвердить | ИБ/доказуемость действий | Нет |
| Push токены | До logout/отзыва/неактуальности устройства | Исполнение функции | Да, при отвязке |
| Чаты — метаданные | **Если SportBuddy78 квалифицирован как ОРИ: 3 года на территории РФ** | 149-ФЗ ст. 10.1 | Нет до решения ОРИ |
| Чаты — содержание | **Если SportBuddy78 квалифицирован как ОРИ: до 6 месяцев в порядке/объеме по применимым актам** | 149-ФЗ ст. 10.1 | Нет до решения ОРИ |
| Рекламные данные/ERID | По срокам обязательной рекламной отчетности и договоров | 38-ФЗ ст. 18.1 | Нет |
| Резервные копии | Отдельный ограниченный цикл; должен позволять выполнение удаления после истечения retention | 152-ФЗ/ИБ | Требует инфраструктурной настройки |

## Правила реализации

1. Ни одна коллекция не получает «вечное хранение» по умолчанию.
2. Ни один cron-delete не запускается для чатов, пока не закрыта квалификация ОРИ.
3. Отзыв публичного согласия прекращает выдачу данных в публичных API немедленно, даже если юридическая доказательная запись согласия остается в закрытом журнале.
4. Удаление аккаунта не должно уничтожать документы/платежные записи, которые оператор обязан хранить.
5. Резервные копии должны иметь документированный срок жизни и процедуру исключения удалённых данных из активной обработки.
6. Конкретные календарные сроки по бухгалтерским, налоговым, рекламным и претензионным документам утверждаются после проверки юристом/бухгалтером и заносятся в этот файл до commercial launch.
