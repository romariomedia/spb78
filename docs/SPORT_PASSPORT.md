# Спортивный паспорт SportBuddy78

## Назначение

Спортивный паспорт — постоянная спортивная история пользователя внутри SportBuddy78. Он не заменяет обычный профиль: профиль отвечает за знакомство и общение, паспорт — за спортивную биографию, подтверждённую активность и достижения.

## Источники данных

Паспорт разделяет данные по уровню доверия:

- **Заявлено** — пользователь сам указал уровень, разряд, опыт или личное достижение.
- **Подтверждено** — зарезервированный уровень для будущей проверки документов/ссылок администрацией.
- **Подтверждено SportBuddy78** — результат получен из серверно-авторитетных данных SportBuddy78: GPS check-in, завершённая тренировка, рейтинг либо официальный результат мероприятия.

Пользователь не может самостоятельно присвоить себе статус SportBuddy78.

## Первая production-версия

В профиль добавлена отдельная карточка SportBuddy78 ID:

- фото;
- имя;
- основной вид спорта;
- район;
- уровень/разряд;
- тренировки;
- медали;
- рейтинг.

По нажатию открывается полный паспорт.

Пользователь может самостоятельно указать:

- основной вид спорта из уже выбранных в профиле;
- уровень;
- разряд/спортивный статус;
- стаж;
- до 10 заявленных достижений.

Сервер валидирует и сохраняет эти данные в users/{uid}.sportPassport.

## Автоматическая история

API паспорта строит историю из авторитетных коллекций, а не из localStorage:

- checkins — подтверждённое присутствие на тренировке;
- trainings — название, спорт, место и организованные тренировки;
- sportPassportResults — будущие официальные результаты соревнований;
- users — агрегаты тренировок, рейтинга и медалей.

История тренировок ограничена последними 20 записями в UI.

## Автоматические достижения

Сейчас автоматически создаются отметки:

- первая подтверждённая тренировка;
- 5 / 10 / 25 тренировок;
- рейтинг 4.5+ при минимум 5 оценках;
- 7 медалей активности.

Эти отметки имеют статус **Подтверждено SportBuddy78**.

## Пустой паспорт

Для новичка показывается:

> Ваш спортивный путь начинается здесь. Первая тренировка уже станет частью вашей истории.

Исторические результаты не выдумываются и не создаются из демо-данных.

## Следующие этапы

Отдельными вертикалями:

1. Verification Center для документов/официальных ссылок → статус **Подтверждено**.
2. Результаты соревнований SportBuddy78 → автоматическая запись в sportPassportResults.
3. Публичная карточка/шеринг паспорта.
4. Спортивные рекорды и дисциплинарная статистика по видам спорта.
