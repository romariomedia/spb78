# Уведомление об обновлении Android

Поля админки minimumAndroidVersion и ruStoreUrl теперь сохраняются и возвращаются app-config. Несмотря на историческое название поля, minimumAndroidVersion содержит целый version_code, не versionName и не версию ОС. Сравнение идёт с App.getInfo().build.

Уведомление доступно только в новом Android APK, включая экран входа. Проверка при запуске и возвращении фокуса/видимости. Есть «Открыть RuStore» и «Позже» (до перезапуска приложения). Это рекомендация, не обязательная блокировка устаревшего клиента и не автоматическая установка APK. Старые APK без компонента уведомление не получат.

Админка принимает только HTTPS-карточку /catalog/app/ru.sportbuddy.mobile на rustore.ru или www.rustore.ru. Номер без ссылки отклоняется. Пока приложение не опубликовано, оба поля оставить пустыми. После публикации и проверки доступности обновления указать его version_code и настоящую ссылку. Не ставить номер сборки, которую ещё нельзя скачать. Очистка номера выключает уведомление.

Развёртывание: сервер/сайт, затем подписанный APK с увеличенным version_code и прежним ключом. На устройстве проверить предложение для меньшего кода, отсутствие для равного/большего, переход в RuStore, кнопку «Позже», работу без сети и отсутствие уведомления в вебе. Здесь выполнены 289 автоматических тестов, production build и Capacitor sync. Реальный переход из Android и установка через RuStore требуют приёмки на устройстве.

Предыдущая миграция каталогов по-прежнему требует проверки нового APK перед публикацией Firestore rules.
