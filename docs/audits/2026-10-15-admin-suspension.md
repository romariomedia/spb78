# Исправление отката блокировки аккаунта

Серверное изменение после 2fccf8d. Новый APK именно для этой правки не требуется.

- Перед изменением читается настоящий disabled из Firebase Auth. При ошибке Firestore восстанавливается именно это значение, а не инверсия запрошенного состояния.
- Профиль, служебная причина ограничения и журнал администратора записываются одной транзакцией.
- Предыдущее activeLooking берётся из актуальных документов внутри транзакции.
- Неудача компенсации Auth больше не проглатывается: админ получает HTTP 503 с указанием проверить Firebase Authentication, сервер пишет код ошибки и UID без токенов.

Проверено 286 автоматических тестов, включая повторную блокировку уже отключённого аккаунта, ошибку аудита и ошибку восстановления Auth.

Предел: Firebase Auth и Firestore не поддерживают общую транзакцию. Этот патч исправляет обычный путь компенсации, но не реализует долговечную очередь восстановления при аварийном завершении процесса и сериализацию конкурирующих команд администраторов. Не считать этот пункт распределённой согласованности полностью закрытым. Требуется отдельный workflow восстановления. Фоновые push и механизм обновления APK этим патчем не меняются.
