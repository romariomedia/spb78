# Выбор площадки и оптимизация клиента — 19.10.2026

В форме создания тренировки есть кнопка выбора из общего каталога. Используется тот же каталог с поиском, картой, сетями и адресами филиалов. Отмена выбора возвращает в заполненную форму. Выбор переносит ID, название, адрес и известные координаты; название тренировки, дата, лимит и описание сохраняются. Вид спорта сохраняется, если площадка его поддерживает. При смене на несовместимый спорт привязка снимается. Можно заменить площадку или убрать привязку, оставив собственную точку встречи.

При отсутствии проверенных координат необходимо выбрать точку на карте. При наличии можно уточнить её, например отметить вход. Согласование посещения/аренды остаётся обязательным и сбрасывается при смене площадки. Ограничения Premium и серверная авторизация не меняются.

Оптимизация:
- Площадки, редактор профиля, тарифы и правовые документы загружаются отдельными чанками по мере открытия.
- Поиск площадок использует отложенное обновление результатов React; группировка сетей мемоизирована.
- Одновременные публичные запросы каталога объединяются; повторное открытие проверяет данные заново.
- Сохранённый публичный каталог показывается сразу. Успешный пустой каталог не заменяется стартовыми карточками при сетевом сбое.
- Админский каталог со скрытыми объектами не записывается в публичный кэш. Старый формат кэша заменён версией v2. Ошибка админского запроса показывается, а не подменяется стартовым каталогом.
- Таймер проверки срока доступа не перерисовывает приложение, пока документ скрыт. Возврат на экран обновляет доступ.

Проверены существующие механизмы: отложенная загрузка ленты, lazy-фотографии карточек, раздельная загрузка карты и админки уже присутствуют. Это целевая оптимизация, а не замер FPS/памяти на реальном телефоне или нагрузочный тест VPS.

После выкладки веб/API требуется новая сборка APK с увеличенным versionCode.
