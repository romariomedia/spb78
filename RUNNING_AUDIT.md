# Проверка пробежек — 11 ноября 2026

Проверена ветка PR #77: клиент, серверные расчёты, авторизация, сохранение/удаление, каталог, привязка маршрута к совместной тренировке, Firestore indexes/rules, регистрация API и удаление данных при удалении аккаунта. Production и реальные устройства в этой проверке не использовались; серверные тесты используют имитацию Firestore.

## Исправлено

- Черновик фиксирует версию маршрута при старте. Результаты старой или неизвестной версии сохраняются только в личную историю и не попадают в текущий рейтинг. Версия участвует в проверке повторной отправки.
- Один GPS-замер может покрыть несколько близких последовательных контрольных точек: плотная эталонная линия больше не требует такого же числа GPS-замеров. Обратное направление и разрывы по-прежнему исключают результат из рейтинга.
- Успешное сохранение больше не выглядит как неудачная отправка, если затем не загрузилась история.
- Ответ рейтинга для ранее открытого маршрута не подменяет результаты другой карточки.
- При смене вида спорта в форме создания тренировки снимается привязка к беговому маршруту.
- Для свободной пробежки убрано сообщение о непроверенной трассе.

## Подтверждено кодом и тестами

Три карты и девять иллюстраций присутствуют. Расстояния карт согласованы с displayPath, парковый круг расположен в парке, центральный проходит через оба моста. Координаты displayPath не используются для автоматического включения рейтинга.

Сервер пересчитывает время/дистанцию, не доверяет присланным итогам, ограничивает размер и длительность трека. Паузы входят в полное время. Повторное сохранение идемпотентно; чужие результаты удалить нельзя. Публикация требует отдельного согласия. Удаление лучшего результата пересчитывает рейтинг. Точный трек не сохраняется в базе, сводки защищены серверной авторизацией, прямой доступ Firestore закрыт. Создание совместной тренировки сохраняет ID и серверную версию маршрута; неверный ID или несовместимый вид спорта отклоняются.

Проверки: npm run build — успешно; полный npm test — 528 passed, 4 skipped, 0 failed (TMPDIR на разделе с достаточным местом); 16 профильных running-тестов — успешно. После добавления отдельной проверки привязки маршрута весь tests/mutations.test.js также проходит. git diff --check — успешно.

## Что ещё не готово к полному выпуску

1. Все маршруты verified=false, рейтинги закрыты. Нужна проверка доступности и направленной геометрии трасс; displayPath сам по себе не подтверждает пригодность для рейтинга.
2. Фоновый сервис Android отсутствует. При блокировке экрана или сворачивании GPS может останавливаться. Текущая версия требует открытого приложения и включённого экрана.
3. Проверить на Android/iPhone разрешения GPS, 200–500 м движения, паузу, возобновление, перезапуск, отсутствие сети, повторную отправку и смену аккаунта. Отдельно проверить дрейф GPS при стоянии и точность дистанции в городе; синтетические тесты этого не доказывают.
4. Расширенной статистики маршрута (число прохождений, периоды, динамика личных результатов) нет. Есть личные последние 50 результатов и серверная основа лучших результатов.
5. Историческая карта пробежки и карточка результата для публикации не реализованы: после сохранения остаётся сводка, черновой трек удаляется.
6. Новые Firestore индексы и согласованные версии клиента/сервера нужно развернуть. Готовность индексов на production не проверялась. VPS/APK не обновлялись.

Решение: пригодно для ограниченного тестирования записи в открытом приложении после развёртывания зависимостей; не считать завершённым продуктом с фоновым GPS, активными рейтингами и полной статистикой маршрутов.
