| Материал | Размер | Формат |
|---|---|---|
| Иконка | 512×512 | PNG без прозрачности |
| Скриншоты | 1080×1920 (мин. 4 шт.) | PNG / JPG |
| Баннер | 1024×500 | PNG / JPG |

### Android (генерируются из `icon-1024.png`)
| Плотность | Размер |
|---|---|
| mdpi | 48×48 |
| hdpi | 72×72 |
| xhdpi | 96×96 |
| xxhdpi | 144×144 |
| xxxhdpi | 192×192 |
| Play Store | 512×512 |

### Adaptive icon
- **Foreground:** `icon-foreground.png` (1024×1024, прозрачный фон, safe-zone 66%)
- **Background:** сплошной цвет `#020617`

## ⚙️ Генерация всех размеров

Автоматически через `@capacitor/assets`:

```bash
npm i -D @capacitor/assets

mkdir -p assets
cp store-assets/icon/icon-1024.png assets/icon.png
cp store-assets/icon/icon-foreground.png assets/icon-foreground.png

npx capacitor-assets generate \
  --android \
  --iconBackgroundColor '#020617' \
  --splashBackgroundColor '#020617'
```

Иконки автоматически разложатся в `android/app/src/main/res/mipmap-*`.

Вручную через ImageMagick:

```bash
for s in 48 72 96 144 192 512; do
  magick store-assets/icon/icon-1024.png -resize ${s}x${s} icon-${s}.png
done
```

## 🖼 Скриншоты

Пять экранов, покрывающих ключевую функциональность:

1. **Знакомства** — свайп-карточки с «живыми» фото
2. **Тренировки** — календарь, мероприятия, карточки занятий
3. **Карта** — радар поиска в радиусе 5 км, онлайн-статусы
4. **Награды** — трёхуровневые медали и SportBuddy BOX
5. **Профиль** — таймер до тренировки, статистика, модули

> Для финальной публикации рекомендуется заменить макеты на реальные
> скриншоты с устройства: `npx cap run android` → снимок экрана 1080×1920.
