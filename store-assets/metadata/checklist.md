# Чек-лист публикации в RuStore

## 1. Сборка

- [ ] `npm run build` — без ошибок
- [ ] `npx cap sync android`
- [ ] `cd android && ./gradlew bundleRelease`
- [ ] AAB подписан релизным keystore
- [ ] `versionCode` увеличен, `versionName` = 1.0.0

## 2. Иконки

- [ ] `store-assets/icon/icon-1024.png` скопирован в `assets/icon.png`
- [ ] `store-assets/icon/icon-foreground.png` в `assets/icon-foreground.png`
- [ ] `npx capacitor-assets generate --android` выполнен
- [ ] Проверена adaptive icon на устройстве (круглая и квадратная маска)
- [ ] Иконка 512×512 загружена в консоль

## 3. Графика карточки

- [ ] Баннер 1024×500 загружен
- [ ] Минимум 4 скриншота 1080×1920 загружены
- [ ] Скриншоты сделаны с реального устройства (рекомендуется)
- [ ] На скриншотах нет отладочных элементов и тестовых данных

## 4. Тексты

- [ ] Название ≤ 50 символов
- [ ] Краткое описание ≤ 80 символов
- [ ] Полное описание ≤ 4000 символов
- [ ] Раздел «Что нового» заполнен
- [ ] Категория: Здоровье и фитнес

## 5. Юридическое

- [ ] Возрастная категория **18+**
- [ ] Политика конфиденциальности доступна в приложении
- [ ] Пользовательское соглашение доступно в приложении
- [ ] Реквизиты правообладателя указаны (ИНН 272199019189)
- [ ] Подтверждена локализация данных в РФ (242-ФЗ)
- [ ] Указан адрес поддержки support@sportbuddy78.ru

## 6. Разрешения — обоснование

| Разрешение | Обоснование для модерации |
|---|---|
| `ACCESS_FINE_LOCATION` | Поиск напарников рядом и отметка о прибытии на тренировку |
| `CAMERA` | Личное фото профиля, портфолио, онлайн-трансляции |
| `READ_MEDIA_IMAGES` | Публикация фото из галереи в ленту |
| `USE_BIOMETRIC` | Быстрый вход по отпечатку пальца |
| `VIBRATE` | Тактильный отклик при мэтче и наградах |
| `INTERNET` | Синхронизация данных и карты |

## 7. Финальная проверка на устройстве

- [ ] Регистрация и вход работают
- [ ] Вход по отпечатку пальца работает
- [ ] Геолокация запрашивается корректно
- [ ] Карта загружается, маркеры отображаются
- [ ] Создание тренировки с выбором даты и точки
- [ ] Отметка о прибытии засчитывает тренировку
- [ ] Медаль за вход начисляется, промокод генерируется
- [ ] Уведомление за 2 часа приходит
- [ ] Приложение не падает при офлайне
- [ ] Все модули сворачиваются и запоминают состояние
