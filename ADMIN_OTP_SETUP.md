# OTP Авторизация для администратора

Я добавил безпарольную систему авторизации администратора через одноразовые коды (OTP), отправляемые на почту `support@sportbuddy78.ru`.

---

## 📋 Компоненты

### 1. **`AdminOTPModal.tsx`** — UI модалка
- Три экрана: запрос кода → ввод кода → активная сессия
- Красивый дизайн с иконками
- Таймер оставшегося времени сессии (1 час)
- Кнопка выхода

### 2. **`adminAuth.ts`** — Сервис авторизации
Функции:
- `sendAdminOTP()` — генерирует 6-значный код и отправляет на почту
- `verifyAdminOTP(code)` — проверяет код, создаёт сессию
- `isAdminSessionValid()` — проверяет, активна ли текущая сессия
- `getAdminSessionTimeRemaining()` — оставшееся время в минутах
- `logoutAdmin()` — завершает сессию

### 3. **`send-admin-otp.js`** — API для отправки писем
Serverless функция на Node.js для отправки красивого HTML-письма с кодом на почту

## ⚙️ Как настроить

### Шаг 1: Переменные окружения
В файле `.env.production` (или на хостинге) добавьте SMTP-параметры:

```bash
# SMTP сервер для отправки писем
SMTP_HOST=smtp.gmail.com           # или ваш SMTP-сервер
SMTP_PORT=587                      # 587 для TLS, 465 для SSL
SMTP_SECURE=false                  # false для 587, true для 465
SMTP_USER=your-email@gmail.com     # Email отправителя
SMTP_PASS=your-app-password        # Пароль или App Password
SMTP_FROM=noreply@sportbuddy78.pro # Email от кого отправлять
```

**Если используете Gmail:**
1. Включите 2FA на аккаунте
2. Создайте [App Password](https://myaccount.google.com/apppasswords)
3. Используйте его в `SMTP_PASS`

### Шаг 2: Развёртывание API
Функция `api/send-admin-otp.js` должна быть доступна по адресу:
```
POST https://sportbuddy78.pro/api/send-admin-otp
```

Если используете **Vercel** — файл автоматически станет функцией.
Если **другой хостинг** — убедитесь, что `nodemailer` установлен:
```bash
npm install nodemailer
```

### Шаг 3: Интеграция в приложение
Кнопка администратора автоматически переключена на OTP-авторизацию.

## 🔐 Как это работает

1. **Администратор нажимает кнопку "🗝️ Кабинет администратора"**
2. **Модалка запрашивает код** (кнопка "📧 Отправить код")
3. **На почту `support@sportbuddy78.ru` приходит письмо с кодом**
   ```
   Ваш одноразовый код: 123456
   Действителен 15 минут
   ```
4. **Администратор копирует код из письма**
5. **Вводит в поле модалки**
6. **Система проверяет код и создаёт сессию (1 час)**
7. **После истечения часа нужно заново запросить код**

---

## 📧 Что приходит в письме

Кодированное HTML-письмо с:
- Броским заголовком 🔐
- Кодом в большом шрифте (легко копировать)
- Временем действия кода (15 минут)
- Предупреждением, что код одноразовый

Стиль письма соответствует брендингу SportBuddy (тёмная тема, изумрудные акценты).

---

## 🛡️ Безопасность

✅ **Коды одноразовые** — после использования удаляются  
✅ **Коды истекают** через 15 минут  
✅ **Сессии имеют срок** — 1 час, затем нужно заново авторизоваться  
✅ **sessionStorage** — коды хранятся в памяти браузера, удаляются при закрытии вкладки  
✅ **SMTP-авторизация** — письма отправляются безопасно

## ❓ Что если код не приходит?

1. **Проверьте SMTP-параметры** в `.env.production`
2. **Логи сервера** (Vercel, Cloud Functions и т.д.)
3. **Спам-фильтр** — письмо может зайти в Spam
4. **Лимиты SMTP** — некоторые сервисы ограничивают отправку
5. **Тестовый email** — попробуйте отправить тестовое письмо через `nodemailer` напрямую
